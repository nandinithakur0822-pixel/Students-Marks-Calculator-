# Student Marks Calculator in C

My first mini project as a B.Tech CSE student!

## About the Project
The Student Marks Calculator is a beginner-friendly C program that calculates a student's academic performance based on the marks entered.

## Features
- Calculates total marks
- Calculates percentage
- Displays grade
- Shows pass/fail status

## Technologies Used
- C Programming

## What I Learned
- Variables and data types
- Taking user input and displaying output
- Conditional statements
- Basic calculations and logical thinking
